# image-studio.css · 功能局部样式

对应源码：`../image-studio.css`。UI 为浅色、低动画、玻璃质感的工作台，主作用域是 `.is-page`，避免污染训练、资源管理、数据集页面。

包含桌面三栏（素材 / 画布 / 参数）、Graph 三栏（节点库 / 画布 / 节点检查器）、平板和手机断点，以及 `prefers-reduced-motion` 的低动画处理。

**维护准则**：只在此文件放图像工作室专属样式；跨页面 Token 与基础组件才进入共享样式层。不要引入高成本动画或使 Canvas 在参数模式后台持续渲染。请在变更布局后执行 `npm run build`，并在实际浏览器验证移动端。
