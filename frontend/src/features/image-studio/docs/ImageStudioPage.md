# ImageStudioPage.tsx · 界面编排

对应源码：`../ImageStudioPage.tsx`。职责：在一个 Image Studio 中组合「文字生成、参考编辑、局部重绘」以及「参数 / Graph」两种视图。

**数据来源**：同一份 `StudioWorkflow`；设置字段时更新节点 `params`，不在 React 表单中另存一套参数。LoRA Stack 使用 0—N 数组并允许独立开关和强度。参考图使用会话对象 URL，蒙版在本地画布绘制和导出；这些二进制数据不被直接放入 Graph JSON。

**运行限制**：模型目录及 Qwen 等能力目前是前端预设，尚未打通实际后端执行。生成按钮只提示未接入，不模拟完成任务。参考图预览采用尺寸限制并回收 URL，避免全尺寸预览资源长期驻留。

**测试入口**：前端 `npm run build`。后续接入上传/生成 API 后需要增加工作流到请求体的组件测试和端到端测试。

## Anima 真实生图闭环（已接入）

- 首选 Anima Base 1.0 模型（当前只支持文字生成）；点击「开始生成」向 [api.ts](api.md) 的本地 FastAPI 提交**唯一 Graph JSON**。
- 后端未配置/权重不存在时显示真实 503 错误，不会伪造完成。
- 用轻量轮询每 1.5 秒读取 SQLite 任务状态；显示排队、运行、失败、取消与生成成功。
- 成功后用 `GET /api/v1/outputs/{output_id}` 加载**真正的 PNG**，显示生成缩略图和随机种子；没有结果仍保留明确标识的示意素材。
- 生成期间可以请求取消，但不是强制终止 CUDA kernel。组件卸载时停止轮询；任务仍在后台 SQLite 队列中，后续可查询历史。
- 生成结果在页面中只保存最近 20 个 URL 元数据，不把整张图片转成 Base64 塞进 React State。


Anima 的默认轻量参数布局展示负面提示词与引导强度，默认没有不支持的透明背景开关；如果用户选择其它模型，前端布局展示与实际推理能力仍分别由 UI 和后端验证决定。
