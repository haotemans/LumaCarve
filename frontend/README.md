# LumaCarve WebUI

React + TypeScript + Vite 前端初版，供 **WebUI 与未来的 Tauri 2 / Rust 桌面壳共用**。

## 启动

需要 Node.js 20.19+ 或 22+。

```bash
cd frontend
npm install
npm run dev
```

打开 http://localhost:5173 。

生产构建：`npm run build`，预览：`npm run preview`。

## 当前已实现（前端）

- 深色响应式工作台，侧边栏导航与快捷键 `/` 搜索。
- **出图管理**：瀑布式网格、收藏、搜索、筛选、批量选择、本地图片导入、参数详情与复制。
- **训练采样**：按任务集合归档；Epoch 时间轴、采样预览与任务对比。
- **数据集管理**：独立页面、图片 / Caption 对照、选择数据集、本地图片与同名 `.txt` 导入、前端编辑 Caption。
- 训练三栏、文生图、模型管理、插件管理、任务历史与设置的可视化 UI。

## 范围说明

这里是**可运行的前端原型**，包含明确标记的示例数据。训练、采样、GPU 监控、模型自动扫描、PNG 内嵌生成元数据写入、磁盘持久化、插件安装等**尚未接入 Python/FastAPI 后端**；按钮不会冒充完成真实训练/生图。浏览器中导入的本地图片与编辑状态在当前会话中可用，刷新页面后不保证保存。后续通过 API 和 WebSocket 接入真实引擎。

未引入外部人物图像，卡片默认使用本地 SVG 绘制的原创占位插画。
