# LumaCarve v0.2.1 Desktop Preview 1 · 琢影

This is an **unsigned experimental desktop preview**, built from the tagged source for **Windows x64 and Linux x64**. It is intended for testing the desktop UI and local management API, **not** for production GPU image generation or LoRA training.

## Downloads

- **Windows x64:** NSIS setup `LumaCarve_0.2.1_x64-setup.exe`.
- **Linux x64:** `.deb` installer and `.AppImage`.
- **Integrity:** `SHA256SUMS.txt` (SHA-256 checksums of all three installers).

## What's new compared with Desktop Preview 1

- **Flexible monitoring UI:** simple/detailed views, adjustable 2/3/5/10-second refresh, pause, optional device selection, and a bounded sampling history.
- **Execution timeline:** actual backend job/model/LoRA/inference/save phase events with durations and status; missing measurements stay explicitly unavailable.
- **Safer model management:** exclusive base-model residency policy, idle-only unload request, and honest loaded/unloaded/unknown states.
- **Isolated Anima GPU executor (source/runtime integration):** spawned Python GPU worker, cancellation and heartbeat monitoring, teardown before replacement, and measured component parameter residency and observable TE/VAE/DiT module forward timings. **These GPU features are implemented in the optional source backend, not included in these lightweight desktop installers.**
- **Backend/API and UI tests:** Python and Vue contract coverage for new monitoring behavior.

## Important limitations

- **Not signed.** Windows SmartScreen or Smart App Control may warn or block installation. Do not disable Windows security features globally.
- The installer bundles the **lightweight FastAPI management sidecar** only. It does **not** bundle PyTorch, CUDA, Triton, the Anima model weights, a ready-to-run GPU inference environment, or LoRA training.
- GPU telemetry requires a suitable NVIDIA driver and optional NVML bindings in a separately configured runtime. GPU executor and TE/VAE/DiT profiling have **not** undergone full physical-GPU end-to-end validation.
- Model editing, training, and additional model families are still under development.
- Linux AppImage may require FUSE. No automatic updater or signing key is configured for this preview.

## Verification

The release workflow builds all three installer artifacts from the **same commit**. It runs frontend and backend tests before packaging, verifies unsigned Windows output, requires all expected platform artifacts, and publishes their SHA-256 checksums. CI packaging is not equivalent to interactive desktop or CUDA hardware QA.
