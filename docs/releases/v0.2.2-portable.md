# LumaCarve v0.2.2 Portable Preview 1 — Windows x64 / Linux x64

**Portable-only desktop preview. No installer packages are distributed.** The Linux AppImage and the Windows ZIP are compiled by separate native GitHub Actions runners from the **same source commit**.

## Download and run

- **Windows x64:** Download `LumaCarve-Windows-x64-Portable.zip` and `SHA256SUMS-Windows.txt` when present. Verify the ZIP hash, extract the entire ZIP to a writable folder and double-click `LumaCarve.exe`. Keep `lumacarve-api.exe` and `portable.flag` beside it. Requires Microsoft Edge WebView2 Runtime. The ZIP is **not** an installer.
- **Linux x64:** Download `LumaCarve_0.2.2_amd64.AppImage` and `SHA256SUMS.txt`, verify `sha256sum -c SHA256SUMS.txt`, run `chmod +x LumaCarve_0.2.2_amd64.AppImage`, then launch it from a writable directory.

Windows ZIP is published to this release **only after** the Linux publish workflow completes successfully and a Windows 2022 runner passes Windows tests, builds Tauri + PyInstaller, verifies the ZIP, and smoke-tests the extracted desktop app and sidecar. The ZIP may not be available immediately when the Linux AppImage first appears. If either platform's checks fail, that platform's asset will be missing. No pre-existing installer assets are reused.

The portable workspace and logs live in an adjacent `LumaCarveData/` directory, not in the system profile. Moving the app folder moves its local data together; no automatic migration from old installer data occurs.

## Limitations

The bundled desktop preview contains a lightweight FastAPI core and the Vue/Tauri UI. **PyTorch, CUDA, Triton, Anima weights and GPU training/inference workers are not included.** This is not a GPU-ready LumaCarve release. The binaries are unsigned and may trigger Microsoft SmartScreen. CI validates packaging and limited smoke tests; real GPU functionality, device compatibility and extended GUI testing remain outstanding.
