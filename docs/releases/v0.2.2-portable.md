# LumaCarve v0.2.2 Portable Preview 1 — Linux x64 only

This prerelease publishes the **portable Linux AppImage** built from this tagged commit; it is not a DEB, MSI, or NSIS installer.

**Included**
- Tauri 2 + Vue 3 desktop interface and bundled lightweight FastAPI API sidecar
- Portable workspace stored next to the AppImage under `LumaCarveData/` (directory must be writable)
- SHA256SUMS.txt for integrity checking

**Not included**
- **Windows ZIP:** There is no verified native Windows build available. Windows portable builds must be compiled and tested locally on Windows; no Windows GitHub Actions runner is used.
- PyTorch, CUDA, Triton, GPU Executor, Anima model weights, and working GPU training/inference. These capabilities must not be represented as ready in this preview.

**Linux instructions**
1. Download the .AppImage and SHA256SUMS.txt from this release.
2. Validate the hash: `sha256sum -c SHA256SUMS.txt`
3. Make the AppImage executable: `chmod +x LumaCarve_0.2.2_amd64.AppImage` (use its actual downloaded filename).
4. Run it from a writable folder; user data will appear in the adjacent `LumaCarveData/` directory.

The AppImage has been compiled and archive-inspected by CI. GUI startup and actual CUDA operations still need real-device testing.

Source: [PR #16](https://github.com/haotemans/LumaCarve/pull/16); [portable distribution policy](https://github.com/haotemans/LumaCarve/blob/main/docs/ci-build.md).
