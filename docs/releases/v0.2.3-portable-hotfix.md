# LumaCarve v0.2.3 Windows Portable Preview — API startup diagnostics hotfix

This is a **Windows x64 lightweight desktop API hotfix**, not a complete GPU-ready LumaCarve release.

## Changes
- Directly launching the internal `lumacarve-api.exe` now displays guidance to open `LumaCarve.exe`, instead of an uncaught PyInstaller traceback.
- The Tauri host continues to choose an absolute portable `LumaCarveData/workspace` directory and start the sidecar automatically with a random loopback port and a per-launch token.
- The UI distinguishes **API disconnected**, **API connected but GPU worker disabled**, and **Anima ready**. Startup errors are visible.
- Windows CI now launches the **packaged** sidecar with a full launch configuration and verifies that authenticated HTTP health returns 200 and unauthenticated access returns 403. It also extracts the ZIP and smoke-tests desktop startup.

## Installation
1. Download `LumaCarve-Windows-x64-Portable.zip` and `SHA256SUMS-Windows.txt`.
2. Check SHA-256, extract the whole ZIP to a writable directory, then **launch only `LumaCarve.exe`**.
3. Do not launch `lumacarve-api.exe` separately. Keep `portable.flag` and the sidecar next to the main executable.
4. The app creates `LumaCarveData/workspace` and `LumaCarveData/logs` next to the executable. Review `LumaCarveData/logs/api.log` if startup fails.

Requires Microsoft Edge WebView2 Runtime. Unsigned software may trigger SmartScreen.

## Scope and limitations
The portable archive bundles Vue/Tauri and lightweight FastAPI. **It does not bundle PyTorch, CUDA/Triton, Anima model weights or the GPU inference/training worker.** LoRA training and real GPU generation are not available in this preview, even if the local API is connected. GPU readiness must be verified in a separate functional distribution.

This release is new and immutable; prior `v0.2.2-portable-preview.1` assets are not modified.
